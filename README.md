# human-in-the-loop-ai
Human-in-the-Loop AI  presentation

## About the Project

This project explains Human-in-the-Loop AI and how humans help AI make safer decisions.

It covers:
- How humans work with AI
- How human feedback helps AI improve
- Safety rules for AI
- Real-life examples in healthcare, online safety, and customer support
